# Diablo Takeover

**Doom** × Diablo · visual · idea by the team

Bring Diablo into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put Diablo into Doom: Fallen Ones, skeletons that stand back up, the Butcher, and a secret cow level that opens when you hit level 3.

## Install

Copy mod.pk3 next to GZDoom and run it with freedoom2.wad (or any Doom 2 IWAD): gzdoom -iwad freedoom2.wad -file mod.pk3. You start on MAP01 with a firebolt hand, a red health orb and a blue mana orb.
